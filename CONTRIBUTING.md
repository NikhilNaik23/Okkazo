# 🤝 Contributing to Okkazo

First off, thank you for considering contributing to Okkazo!

We welcome contributions that improve the project, fix bugs, enhance documentation, or introduce new features.

---

# Development Workflow

1. Fork the repository.
2. Create a new branch.
3. Make your changes.
4. Commit your changes.
5. Push your branch.
6. Open a Pull Request.

---

# Branch Naming

Please use the following naming convention:

```

feature/feature-name
bugfix/issue-name
hotfix/fix-name
docs/documentation-update
refactor/module-name

```

Examples:

```

feature/event-search
feature/chat-module
bugfix/login-validation
docs/update-readme

```

---

# Commit Message Convention

Follow meaningful commit messages.

Examples:

```

feat: add event booking API
fix: resolve login authentication issue
docs: update architecture documentation
refactor: optimize event service

```

---

# Coding Standards

## Backend

- Follow REST API principles.
- Keep services modular.
- Use meaningful variable names.
- Write reusable code.
- Validate all inputs.

---

## Frontend

- Use reusable React components.
- Keep components small.
- Avoid duplicate code.
- Follow consistent folder structure.

---

## Mobile

- Follow React Native best practices.
- Keep screens modular.
- Separate UI from business logic.

---

# Pull Requests

Before creating a Pull Request:

- Ensure the project builds successfully.
- Test your changes.
- Update documentation if necessary.
- Resolve merge conflicts.
- Keep commits clean.

---

# Reporting Issues

Please include:

- Description
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots (if applicable)

---

# Feature Requests

Feature requests should include:

- Problem Statement
- Proposed Solution
- Expected Benefits

---

# Code Review

Every Pull Request should be reviewed before merging.

Reviewers should check:

- Code quality
- Readability
- Functionality
- Documentation
- Performance
- Security

---

# Documentation

If your contribution changes project behavior, please update the relevant documentation.

---

# Thank You

Thank you for contributing to Okkazo and helping improve the project!
